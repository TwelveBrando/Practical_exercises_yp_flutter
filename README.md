# Практическая работа 2 — агентство Alibi

Минималистичное Flutter Web приложение для каталога клиентов и заявок вымышленного агентства по созданию бытовых алиби. Все демонстрационные ситуации относятся к повседневным случаям: опоздания, забытые встречи и сорванные сроки.

## Запуск

```powershell
flutter pub get
flutter run -d chrome --web-port=5555
flutter analyze
flutter build web
```

## Основные адреса

- `/requests` — список заявок;
- `/requests?search=планёрка&type=lateForWork&status=inProgress&dateFrom=2026-01-01&dateTo=2026-06-30&sort=eventDate,desc&page=2&size=10` — фильтры, сортировка и страница в URL;
- `/requests/1` — карточка заявки;
- `/clients` — список клиентов;
- `/clients?city=Москва&search=Иван&sort=name,asc&page=1&size=10` — фильтруемый список клиентов;
- `/clients/1` — карточка клиента.

## Слои приложения

Модели и параметры списков находятся в `lib/models`, демонстрационные данные — в `lib/data`, интерфейсы и реализации репозиториев — в `lib/repositories`, Provider-состояние — в `lib/state`, экраны — в `lib/screens`, общие элементы интерфейса — в `lib/widgets`. Клиент связан с заявками отношением один-ко-многим. Общий `EntityTable<T>` показывает таблицу на широком экране и карточки на узком.

Поиск применяется с задержкой 350 мс. Фильтры, сортировка и пагинация хранятся в адресе и восстанавливаются при прямом открытии ссылки. Для демонстрации сетевой ошибки нажмите «Демо ошибки». Удаление поддерживает корзину, окончательное удаление, восстановление и массовый выбор.
